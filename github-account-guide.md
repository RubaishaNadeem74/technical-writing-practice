# How to create a GitHub account
## Introduction
This guide explains how to create a GitHub account. It's for beginners who have never created a GitHub account before. Follow the steps below.
## Before you begin:
Make sure you have:
- A Computer or a Phone.
- A stable Internet connection.
- A web browser.
- An email address you can access.
# Create your GitHub account
### Step 01: Open the GitHub Website
Open your web browser and go to (www.github.com).
### Step 02 Click Create Account
1. Click create account.
2. Enter your email.

**Note:** 
- If you already have a GitHub account, click sign in instead.
- You can continue with Google or Apple.
### Step 03: Enter your Password
- Enter your password.

**Note:** 
- Your password must be at least 15 characters OR at least 8 characters including a number and a lowercase letter.
### Step 04: Enter username
- Enter your username.

**Notes:**
- Username may only contain alphanumeric characters or single hyphens, and cannot begin or end with a hyphen.
- If prompted, select your country/region.

Now click, **Create account**.
### Step 05: Verify email
1. Check your email for the verification code.
2. Enter the verification code on GitHub.

**Note:** If you don't receive the verification code, wait a few minutes and check your spam folder. If you still don't receive it, use the option to resend the code.
# Tips
- create a strong password.
- Do not share your password with anyone.
- If you have trouble verifying your email address, see GitHub's documentation on email address.
# Conclusion
You have succesfully created your GitHub's account.
